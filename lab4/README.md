# AOIS4

Консольный проект с реализацией хеш-таблицы для строковых ключей из русских букв.
Таблица поддерживает вставку, поиск, обновление и удаление элементов, а также вывод
текущего состояния и коэффициента заполнения.

## Что делает проект

Ключи проходят нормализацию:

- обрезаются пробелы по краям;
- переводятся в верхний регистр;
- проверяются на длину не меньше двух символов;
- проверяются на принадлежность русскому алфавиту.

Хеш рассчитывается по первым двум буквам ключа. При коллизиях таблица сначала
использует квадратичное пробирование, а затем при необходимости добирает
непросмотренные позиции линейным проходом. Это позволяет не терять свободные
ячейки из-за повторяющихся квадратов по модулю размера таблицы.

Удаленные элементы помечаются как `DELETED`, поэтому:

- поиск продолжает идти дальше по цепочке пробирования;
- освобожденные позиции могут быть использованы повторно.

## Структура проекта

- `src/hash_utils.py` - валидация ключей, работа с алфавитом и вычисление хеша;
- `src/hash_table.py` - основная логика хеш-таблицы;
- `src/hash_entry.py` - описание ячейки таблицы;
- `src/hash_status.py` - статусы ячеек (`EMPTY`, `OCCUPIED`, `DELETED`);
- `src/errors.py` - пользовательские исключения проекта;
- `cli.py` - консольный интерфейс;
- `main.py` - точка входа;
- `tests/` - модульные тесты.

## Требования

- `uv`
- Python 3.12+

## Подготовка окружения

```bash
uv sync
```

Если интерпретатор Python 3.12 еще не установлен, его можно поставить через `uv`,
а затем повторить синхронизацию:

```bash
uv python install 3.12
uv sync
```

## Запуск проекта

```bash
uv run main.py
```

После запуска откроется консольное меню, где можно:

- добавить элемент;
- найти элемент;
- обновить значение;
- удалить элемент;
- вывести таблицу;
- посмотреть коэффициент заполнения.

## Запуск тестов

```bash
uv run python -m unittest discover -v
```

## Проверка покрытия

Если установлен пакет `coverage`, можно использовать привычный отчёт:

```bash
uv run python -m coverage run -m unittest discover
uv run python -m coverage report -m
```

Если дополнительных пакетов нет, покрытие можно проверить стандартным модулем
`trace`:

```bash
uv run python -m trace --count --summary --missing --ignore-dir "<PYTHON_LIB_DIR>" --module unittest discover
```

Если нужен `coverage`, его можно добавить в dev-зависимости:

```bash
uv add --dev coverage
```

При последней проверке исходные модули проекта имели `100%` line coverage по `trace`.

## Что покрыто тестами

Тесты проверяют:

- нормализацию и валидацию ключей;
- корректность вычисления хеша;
- вставку без коллизий и с коллизиями;
- повторное использование удаленных ячеек;
- скрытый дефект с неполным обходом коллизий;
- обработку ошибок;
- работу CLI;
- запуск приложения через `main.py`.
